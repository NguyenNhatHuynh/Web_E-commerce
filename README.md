# Design UI - Web E-commerce - Online Clothing Store 👗🛒

## Overview

Welcome to **Design UI Web E-commerce - Online Clothing Store**! This is a modern and responsive e-commerce website built using **HTML**, **CSS**, and **JavaScript**. The website is designed to provide a seamless shopping experience for customers, allowing them to browse, filter, and purchase clothing products from various categories. This project focuses on the frontend design and user experience.

## Features

- [x] **Responsive Design:** Optimized for both mobile and desktop devices.
- [x] **Product Browsing:** Browse a wide variety of clothing items across different categories (e.g., Men, Women, Kids).
- [x] **Product Filtering:** Filter products by size, color, price, and category.
- [x] **Search Functionality:** Quickly search for products using the search bar.
- [x] **Product Detail Page:** View detailed information about each product, including images, descriptions, and prices.
- [x] **Shopping Cart:** Add products to your cart, adjust quantities, or remove items.
- [x] **Checkout Page:** Simulate a checkout process with user information and order summary.
- [x] **Dynamic Product Gallery:** Display products in grid and list formats, with hover effects to reveal more details.
- [x] **Promo Banner:** Display promotional offers and discounts on the homepage.

## Technologies Used

- **Languages:** HTML, CSS, JavaScript
- **Libraries & Frameworks:** None (Vanilla JS, Custom CSS)
- **Development Tools:** Visual Studio Code, Browser Developer Tools

## Pages of the Website

- **Home Page:** Displaying featured products, banners, and promotions.
- **Shop Page:** Displaying the product catalog with filters and sorting options.
- **Product Detail Page:** Showing detailed information for a single product.
- **Cart Page:** Displaying the items added to the cart, with options to update quantity or remove.
- **Checkout Page:** A simulation of the checkout process with order summary.
- **About Us Page:** Information about the store and its values.
- **Contact Page:** A contact form for customer inquiries.

## Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:

- A web browser (Google Chrome, Mozilla Firefox, etc.)
- A text editor (e.g., [Visual Studio Code](https://code.visualstudio.com/))

### Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/NguyenNhatHuynh/Web_E-commerce.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Web_E-commerce
    ```

3. Open the `index.html` file in your preferred browser to view the website.

### Running the Website Locally

Simply open the `index.html` file in any modern browser to start browsing the site. There’s no server-side backend required for this frontend project, making it easy to get started locally.
